# IBM Cybersecurity Bootcamp Final Project

This repository contains the source code, dependencies, and risk assessment report for the IBM SkillsBuild / BharatCares Cybersecurity Capstone Project.

## Files Included
- `scanner.py`: Python script for automated HTTP security header audits.
- `requirements.txt`: Python package dependency specification.
- `report.pdf`: Detailed project report and NIST risk assessment.
- `README.md`: Project documentation and execution instructions.

## Running the Code
1. Install dependencies: `pip install -r requirements.txt`
2. Run script: `python scanner.py`
